# SlugSwap brand assets

The primary mark is a cleaned vector trace of
`../logo-concepts/refined-arch-icon.png`. The traced slug contour preserves the
approved S-curve, head, antennae, and base; the arch was reconstructed from its
visible semicircular boundary so it remains geometrically clean behind the
slug.

The wordmark is an outlined, custom-spaced treatment of **Figtree SemiBold**.
The glyphs retain the font's native proportions, with slightly negative
tracking and optical pair adjustments to match the generated concept more
closely. The SVGs contain paths rather than live text, so they do not depend on
the font at runtime.

## Palette

- Forest: `#183D32`
- Gold: `#F4C332`
- Cream: `#F6F1E5`
- Soft white: `#FFFDF7`

## Files

- `slug-swap-mark.svg`: primary standalone mark
- `slug-swap-wordmark.svg`: outlined wordmark
- `slug-swap-lockup.svg`: primary horizontal lockup
- `*-inverse.svg`: dark-background variants
- `*-mono.svg`: one-color reductions
- `slug-swap-app-icon.svg`: cream app-icon artwork
- `*.png`: raster previews/exports
- `source/Figtree-VariableFont_wght.ttf`: wordmark source font
- `source/OFL-Figtree.txt`: Figtree license

The isolated raster concepts remain unchanged in `../logo-concepts/` for
comparison and future revisions.
